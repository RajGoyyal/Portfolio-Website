# Raj Goyal — Portfolio Website

Responsive single-page portfolio built with HTML, CSS, and a small JavaScript footer-year update.

## Sections
- Introduction / hero
- About
- Projects
- Skills
- Learning journey
- Contact

## Run locally
Open `index.html` in a modern browser, or use VS Code Live Server. No package installation or build step is required.

## Before publishing
- Replace education and contact placeholders with verified details.
- Replace generic GitHub and LinkedIn links.
- Link only projects that exist and that you can explain.
- Capture genuine desktop and mobile screenshots.
- Upload `index.html`, `README.md`, and screenshots to GitHub.

## Accessibility and responsive design
Includes semantic sections, labelled navigation, visible keyboard focus, responsive breakpoints, and reduced-motion support.
